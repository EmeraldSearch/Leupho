À propos de la run

Cette run consiste à marcher jusqu'aux Far Lands dans Minecraft Beta 1.7.3, la dernière version avant leur suppression. Les Far Lands se trouvent à 12 550 821 blocs en X négatif.

La run se fait à pied, sans aucune aide externe, en survie normale.

Règles

  • Survie normale, difficulté normale
  • Pas de triche, pas de commandes
  • Les morts sont autorisées
  • Le sommeil est autorisé pour passer les nuits

Questions fréquentes

Combien de temps ça prendra ?

À une pace d'environ 5 bl/s en moyenne, la run prend environ 700 heures de jeu. Voir la page Pace pour l'ETA estimé.

Pourquoi Beta 1.7.3 ?

C'est la dernière version de Minecraft à contenir les Far Lands dans leur forme originale. Ils ont été supprimés en Beta 1.8.

Comment fonctionne le tracker ?

Un script Python lit le fichier level.dat à chaque autosave (toutes les 2 secondes) et enregistre la position, la santé, l'inventaire et d'autres statistiques dans une base de données SQLite.

Infos techniques

Le tracker est open source. Il tourne en local sur le PC de stream et publie les données toutes les 5 minutes sur GitHub Pages.
